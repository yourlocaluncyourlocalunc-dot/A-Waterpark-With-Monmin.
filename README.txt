# A Waterpark With Monmin

A responsive static website inspired by the supplied Stanky Shores screenshot.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository, for example `waterpark-with-monmin`.
3. Upload the contents of this folder (make sure `index.html` is at the repository root).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.
7. Wait a minute or two. GitHub will show your public website address on the Pages settings screen.

## Customise
- Replace `assets/pool-hero.jpg` with your own waterpark photo (keep the same filename).
- Replace the example review in `index.html` with a real review.
- Edit attraction and news text in `index.html`.
- Edit colours and layout in `style.css`.

This is a static site: no paid hosting, server, or database is required. Google Fonts is used when internet is available; the site falls back to Arial if it is not.
